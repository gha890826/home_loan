# 房貸與資產成長試算 (Home Loan Calculator)

一個純前端（HTML/CSS/JS）的房貸與資產成長試算工具，可部署於 GitHub Pages。

## 功能

1. **結構化看房紀錄與房貸試算**：每個物件保存一組看房日期與備註，以及自己的頭期款、利率、貸款年限、還款方式與房貸負擔比。貸款金額以房屋總價加車位價格再扣頭期款計算；再次看屋時編輯同一物件更新，不另建看屋紀錄。
2. **物件比較**：勾選物件後並排比較基本資料與房貸結果。房屋單價仍以不含車位的房屋總價計算；購屋總價、貸款與資產試算均包含車位。實際坪數、單價及管理費總額依各物件欄位計算。
3. **JSON 匯入／匯出**：資料保存在目前瀏覽器，透過匯出 JSON 在裝置間手動交換。匯入時以每筆紀錄 ID 合併，更新時間較新的版本覆蓋較舊版本；時間相同時保留本機版本。刪除以 `deleted` 標籤保留，可在 JSON 中移除標籤並更新 `updatedAt` 復原。JSON 含地址等個人資料，請使用私人方式保存與傳送。

舊版 `schemaVersion: 1` JSON 匯入時會將 `visits` 合併到對應物件的 `visitedAt` 與 `notes`，並以新版格式保存。
4. **現有資產**：填入現有現金與現有股票市值。
5. **每月投入與成長率假設**：
   - 每月現金存款、現金年化成長率
   - 每月定期定額投入股票、股票年化成長率
   - 試算年限
6. **試算結果**：以圖表與逐年明細表呈現所選物件的房貸剩餘、累積現金、累積股票與淨資產隨時間的變化。
7. **Cookie 記憶**：自動保存資產與投資假設，重開頁面時還原；可清除已記憶的設定。

### 跨裝置同步

從有最新資料的裝置匯出 JSON，再於另一台裝置匯入；合併後再匯出更新檔供後續交換。這是手動同步，不支援即時共編。若兩台裝置同時修改同一筆資料，匯入時會以較新的 `updatedAt` 為準。

資產成長試算可選擇已記錄的物件，沿用該物件的房價與貸款條件；也可選擇「目前表單資料」試算尚未儲存的情境。

## 本機預覽

直接用瀏覽器開啟 [index.html](index.html) 即可，無需安裝任何套件。

## 部署到 GitHub Pages

### 方式一：GitHub Actions（已內建）

本專案已包含 [.github/workflows/deploy.yml](.github/workflows/deploy.yml)，推送到 `main` 分支後會自動建置並部署。

1. 到 GitHub repository 的 **Settings > Pages**
2. Source 選擇 **GitHub Actions**
3. Push 到 `main` 分支即可自動部署

### 方式二：直接使用分支部署

1. 到 **Settings > Pages**
2. Source 選擇 `Deploy from a branch`，選擇 `main` 分支、`/ (root)` 目錄
3. 儲存後等待數分鐘即可透過 GitHub Pages 網址存取

## 檔案結構

```
index.html   # 主頁面
style.css    # 樣式
script.js    # 計算邏輯（房貸攤還、資產成長模擬、圖表渲染）
```

> 本工具僅供試算參考，實際貸款與投資結果請以銀行與市場實際狀況為準。
